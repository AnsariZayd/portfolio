# Zayd Ansari — Portfolio
React 18 + Vite + Tailwind CSS v4. Edit `src/data.js` to change all content.
```
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```
Put your resume at `public/resume.pdf`. Deploy `dist/` to Vercel / Netlify / Cloudflare Pages / GitHub Pages.

Optional: add `public/profile.jpg` (square photo) for the hero card; initials show until you do.
